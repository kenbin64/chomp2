# Chomp 3D: Wally's Cairns Adventure

**Personal portfolio / skills demonstration: not a commercial product.** Made by Ken Bingham to show
employers his skills. Free and open to everyone to play at https://playbutterflyfx.com/chomp/.

Wally is an ordinary crocodile at a croc park in Cairns, Far North Queensland, until he finds a
sceptre at the bottom of the pond. A 3D browser game across seven places in the region.

- How it was made: [about.html](about.html#made)
- Licence: [LICENSE.md](LICENSE.md) (the source is open to read; it is not an open-source licence)
- Releases and rollback: [RELEASING.md](RELEASING.md), [CHANGELOG.md](CHANGELOG.md)
- Run it locally: `node serve.mjs`, then open http://localhost:8090
- Tests: `npm test` (unit), `npm run e2e` (in Chrome)
